## Activity: Cardano Node Setup Workshop

- **Date:** 19 May 2026
- **Event:** Open Source Summit North America 2026
- **Location:** Hybrid – live-streamed to the event in Minneapolis, Minnesota
- **Format:** Live technical workshop and demonstrations
- **Organised by:** Harun Waweru Mwangi, Dan Baruka, Emmanuel Titi, and Uche Obasi

The workshop introduced developers to practical ways of running Cardano infrastructure, moving from a lightweight local development network to a synced Preview relay node and the fundamentals of setting up a block-producing node.

Dan demonstrated Yaci DevKit as a fast local environment for development and testing. I then demonstrated how to run a Cardano relay node on Preview using Docker, before Emmanuel extended the walkthrough into stake-pool registration and block-producing node concepts. Uche supported the session and directed participants to the DevEx portal and weekly Working Group sessions for follow-up.

---

## My Contribution

I helped organise and present the workshop as part of the joint Developer Advocate team. During the live session, I:

- Helped coordinate the demonstration sequence around the available session time.
- Explained the hardware and storage requirements for running a Cardano node.
- Demonstrated cloning the workshop repository and starting a relay node through Docker.
- Showed how to verify that the node was connected and fully synced to Cardano Preview using `cardano-cli query tip`.
- Explained the distinction between a relay node used for querying and submitting transactions and a block-producing node.
- Directed attendees to the Developer Advocate one-on-one schedules for continued technical support.
