# Contributing

Thanks for your interest in improving the humanise-text skill.

## 3-Step Process

1. **Fork** this repo
2. **Edit** — add missing AI patterns, improve detection scripts, fix false positives, contribute before/after examples
3. **Open a PR** with a clear description of what changed and why

## What We're Looking For

- AI words or phrases the detector misses (with statistical evidence if possible)
- False positives — words flagged as AI that humans use naturally in context
- Structural tells not yet catalogued
- New before/after examples in different domains (legal, medical, technical)
- Detection script improvements (accuracy, performance)
- Validation threshold tuning

## Guidelines

- Test your changes against real AI-generated text before submitting
- If adding a banned word, include the human alternative and reasoning
- One PR per change — don't bundle unrelated edits
