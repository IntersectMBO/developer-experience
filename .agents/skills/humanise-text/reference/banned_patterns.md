## 2. Yellow-Flag Words (Max 1 Per Document)

- crucial

**Rule:** One yellow-flag word per document maximum. If the word appears in the input, replace all but one instance. Prefer the instance where the word is most precise and least replaceable.

## 4. Copula Avoidance Table

AI systematically replaces simple "is/are/has" with elaborate alternatives. The usage of "is" and "are" dropped over 10% in academic writing post-2023. Always prefer the simple form.

| AI Prefers | Human Would Write |
|---|---|
| serves as a | is a |
| stands as a | is a |
| marks a | is a |
| represents a | is a |
| boasts | has |
| features | has |
| offers | has |
| showcases | has / shows |
| constitutes | is |
| embodies | is |

**Detection rule:** Search for "serves as," "stands as," "marks a," "represents a," "boasts," "features," "offers," "showcases," "constitutes," "embodies." If the verb can be replaced with "is," "are," or "has" without losing meaning, replace it.

## 6. Nominalization Patterns

AI loves turning verbs into abstract nouns, burying the action and removing the actor.

### Detection Rule

Look for noun suffixes hiding a verb: **-tion, -ment, -ance, -ence, -ity, -ness, -ism**. If the sentence also contains "was," "were," "is," "are," or "there is/are," you almost certainly have a nominalization to fix.

### The Fix

Find the hidden verb inside the noun. Make it the main verb. Name the actor.

| Nominalized (AI) | De-nominalized (Human) |
|---|---|
| "The implementation of the system was completed" | "We implemented the system" |
| "An investigation was conducted" | "We investigated" |
| "There was an increase in participation" | "More people joined" |
| "The evaluation of the results revealed..." | "When we evaluated the results, we found..." |
| "The decision was made to proceed" | "We decided to proceed" |
| "Consideration should be given to..." | "Consider..." |
| "The establishment of a committee" | "We formed a committee" |
| "A reduction in costs was achieved" | "We cut costs" |
| "There is a need for improvement" | "This needs to improve" |
| "The application of pressure resulted in..." | "Pressing it caused..." |

### Common Nominalizations to Watch For

| Nominalization | Hidden Verb |
|---|---|
| implementation | implement |
| investigation | investigate |
| evaluation | evaluate |
| consideration | consider |
| establishment | establish |
| reduction | reduce |
| application | apply |
| decision | decide |
| improvement | improve |
| development | develop |
| assessment | assess |
| achievement | achieve |
| management | manage |
| requirement | require |
| involvement | involve |
