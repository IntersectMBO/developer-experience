# Notable Contributors

This page credits people whose work changed the site or the working group in a way a reader can point at. A credit here is for something specific rather than for showing up: a security report we acted on, or a run of landed work in this repository.

## Security

**[John Saigle](https://github.com/johnsaigle)** ([@johnsaigle](https://github.com/johnsaigle)), Asymmetric Research, reported the Discord server invites published across this site. An invite code is access, so anyone reading one of our pages could walk into the server with it, and we could not revoke a single invite without breaking every page that carried it. Every invite on the site is now a membership link and the channel names stayed. Thank you, John.
